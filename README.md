# Equilibrium Shell (esh) | WIP

> A lightweight Unix command-line interpreter written in pure C.

## Особенности (Features)

* **REPL-архитектура:** Чёткое разделение на этапы чтения (*Reader*), лексического анализа (*Tokenizer/Parser*) и исполнения (*Executor*).
* **Безопасная работа с памятью:** Динамическое выделение буферов (`getline`, `realloc`), предотвращение утечек памяти при ошибках перевыделения.
* **Управление процессами:** Запуск бинарных утилит через связку POSIX-вызовов `fork()`, `execvp()` и `waitpid()`.
* **Встроенные команды (Built-ins):** Исполняются внутри родительского процесса без накладных расходов на создание дочерних процессов:
  * `cd [path]` — навигация по каталогам (поддержка перехода в `$HOME` по умолчанию).
  * `pwd` — вывод текущей рабочей директории.
  * `echo [args...]` — форматированный вывод переданных аргументов.
  * `help` — список доступных встроенных команд.
  * `exit` — корректное завершение сессии шелла.
* **Строгие стандарты сборки:** Компиляция со строгими флагами проверок (`-Wall -Wextra -Werror -pedantic -std=c11`).

## Архитектура проекта

```text
Equilibrium/
├── include/
│   ├── executor.h   # Прототипы функций исполнения и встроенных команд

├── src/
│   ├── executor.c   # Системные вызовы (fork/execvp/chdir), диспетчеризация команд

│   ├── parser.c     # Парсер аргументов на базе strtok_r
│   └── reader.c     # Динамическое чтение пользовательского ввода
├── Makefile         # Сборочный сценарий проекта
└── README.md
```

## Требования

* Компилятор С с поддержкой стандарта С11 (`gcc` или `clang`)
* Утилита `make`
* POSIX-совместимая ОС

## Сборка и запуск
### Клонирование репозитория
```bash
git clone https://github.com/kektvar/Equilibrium.git
cd Equilibrium
```
### Сборка
```bash
make
```

### Запуск
```bash
make run
```

## В планах

* Обработка системных сигналов (`SIGINT` / `Ctrl+C`, `SIGTSTP` / `Ctrl+Z`) через `sigaction`.
* Перенаправление стандартных потоков ввода/вывода (`>`, `<`, `>>`) через `dup2()`.
* Поддержка конвейеров команд (Pipes `|`).
* Кастомизируемый цветной prompt с отображением текущей ветки Git и директории.
